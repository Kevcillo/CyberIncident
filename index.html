Información del sistema

CyberIncident permite registrar, consultar, filtrar y monitorear incidentes de seguridad de forma organizada. Los datos se obtienen de la API del servidor y se guardan en una base de datos SQLite, por lo que se conservan aunque el servidor se reinicie.

Recomendación

Mantenga actualizada la información de cada incidente para facilitar su seguimiento y resolución.

CyberIncident - Proyecto académico de Desarrollo Web

Plataforma demostrativa para la gestión de incidentes de ciberseguridad. Unidad 2: JavaScript moderno, DOM, Fetch API, ARIA, jQuery, arquitectura MVC, API REST con Express y base de datos SQLite.
