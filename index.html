        Información del sistema

        CyberIncident permite registrar, consultar, editar, eliminar y filtrar incidentes de seguridad. El acceso requiere iniciar sesión: el administrador puede realizar todas las acciones y el analista todas excepto eliminar. Los datos se guardan en PostgreSQL en producción y en SQLite en desarrollo.

        Recomendación

        Mantenga actualizada la información de cada incidente para facilitar su seguimiento y resolución.

        CyberIncident - Proyecto académico de Desarrollo Web

        Plataforma para la gestión de incidentes de ciberseguridad. JavaScript moderno, Fetch API, ARIA, jQuery, arquitectura MVC, API REST con Express, PostgreSQL en producción, SQLite en desarrollo y seguridad con JWT.
